# Continue-with provider icons

Small decorative provider marks are self-hosted here, displayed before the existing accessible text in circular badges. No icon CDN or authentication SDK is loaded to render them.

Sources retrieved 6 November 2026:
- Google light round icon: https://developers.google.com/static/identity/images/branding_guideline_sample_lt_rd_sl.svg ; branding: https://developers.google.com/identity/branding-guidelines
- Microsoft symbol: https://learn.microsoft.com/en-us/entra/identity-platform/media/howto-add-branding-in-apps/ms-symbollockup_mssymbol_19.svg ; branding: https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps
- Facebook, Apple, GitHub: https://github.com/simple-icons/simple-icons/tree/develop/icons ; CC0 license copied as SIMPLE-ICONS-LICENSE.md. Provider names and marks remain their respective owners' trademarks.

SVG files are served as decorative img elements with empty alt text; visible provider labels supply the accessible name. Google keeps its supplied multicolor mark and white circular background. Other marks preserve their recognizable silhouettes; Facebook uses a blue badge with white mark. Enabled and disabled options both retain their icon and label. Keep these source notes when replacing assets.
